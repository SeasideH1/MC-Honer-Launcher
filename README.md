# MC Honer

[English](README.en.md) · 中文

MC Honer 是一个正在开发的 Minecraft: Java Edition 启动器，面向 Windows。它将账号、游戏实例和整合包更新放在同一个客户端中管理，减少切换整合包时重复配置环境、下载文件和维护不同版本的操作。

当前版本为 `0.1.0-alpha.1`。本仓库先公开项目介绍和图片，暂不发布源码与程序包。

## 功能

每个游戏实例保存各自的版本、账号选择和启动设置。客户端支持创建、导入实例，管理 Java 运行时，下载游戏文件并启动游戏。整合包更新按签名清单校验文件；遇到本地配置修改时提供冲突处理，更新中断后可进行恢复。世界存档仍需单独备份。

账号登录采用 Microsoft 设备码授权，用户在系统浏览器中完成登录。客户端已实现 Microsoft、Xbox Live 和 Minecraft Services 的认证流程，用于取得游戏身份、读取资格信息和玩家资料。本项目的应用申请尚未完成，实际授权仍需在获批后测试。

项目还包含主服务和可自行部署的整合包分发服务。主服务管理平台账号、好友、邀请和访问资格，分发服务负责发布版本和限流下载。平台账号由核实后的 Minecraft 身份建立，无需另设密码；游玩统计由游戏服务端上报，本机游客计时单独保存。

## 开发进度

客户端使用 Electron，业务逻辑使用 Node.js，本地数据存储于 SQLite；主服务使用 PostgreSQL。启动器与游戏服务端分别运行，统计与准入适配器只安装在服务端。

2026 年 10 月 13 日的开发测试覆盖了 Windows 客户端与便携包运行、本机签名更新和 PostgreSQL 服务。在 Minecraft `26.4 Snapshot 3`、Fabric `0.19.5`、Java `25.0.1` 的独立环境中，离线账号已进入游戏主菜单并正常退出。OPL 已完成同机双节点连接测试，跨网络连接尚待测试。

正版登录和进服、完整玩家会话统计、公网部署及容量测试尚未完成。候选程序尚无 Windows 代码签名；启动器自动更新、可执行插件扩展及 Linux / macOS 版本暂未提供。具体依赖、配置方式和测试限制见[开发说明](docs/development.zh-CN.md)。

MC Honer 是独立第三方项目，与 Microsoft 或 Mojang 没有隶属关系，也未获其背书。软件与素材的来源、第三方许可及分发说明见 [NOTICE.md](NOTICE.md)。
