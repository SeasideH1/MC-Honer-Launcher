# MC Honer

[English](README.en.md) · 中文

MC Honer 是面向 Minecraft: Java Edition 的 Windows 桌面启动器，用于在同一界面中管理游戏账号、独立实例、整合包下载与更新。项目同时实现主服务和可自行部署的远程分发服务，为整合包维护者提供签名发布、访问资格管理和服务端游玩统计。

项目目前处于开发阶段，内部版本为 `0.1.0-alpha.1`。本仓库仅发布项目介绍与图片，供用户、开发者和应用审核人员了解项目；暂不提供源码、可执行程序或部署包，也不代表已完成 Microsoft / Minecraft API 审核或正式发行验收。

## 当前功能

启动器已实现实例创建与导入、按实例保存设置、Java 运行时管理、游戏文件下载及进程启动。整合包更新采用签名清单和文件校验，并提供用户配置冲突处理与事务恢复机制。更新恢复不替代独立的世界存档备份。

Microsoft 登录使用设备码授权：启动器打开系统浏览器，由用户在微软网页完成登录，应用内不要求输入微软密码。代码包含 Microsoft、Xbox Live、XSTS 和 Minecraft Services 的认证流程，以及 Minecraft 资格信息与玩家资料读取；使用本项目应用 ID 的真实授权仍待审核完成后验证。

主服务负责核实 Minecraft 身份、建立平台账号、管理好友与邀请、签发远程访问资格并汇总统计，不设置独立的平台密码。远程端负责整合包描述、签名版本发布、文件分发和下载限流。可信游戏服务端通过仅服务端适配器上报会话事件；本机游客计时与服务端确认的游玩时长分开处理。

OPL 联机适配已实现，并完成同机双节点隧道检查；跨网络连接和玩家经隧道登录尚未验证。可执行插件扩展、启动器自动更新和 Linux / macOS 发行尚未交付。房间系统、武器配装和 SSH Editor 不属于当前交付范围。

## 实现与部署边界

| 组件 | 当前实现与职责 |
| --- | --- |
| Windows 客户端 | Electron 桌面窗口；本地 Node.js 核心和 SQLite 管理实例及任务。界面通过限定的 IPC 操作访问核心。 |
| 主服务 | Node.js 与 PostgreSQL；负责身份核验、社交、目录、访问资格和统计汇总。 |
| 远程分发服务 | Node.js；使用签名清单、不可变内容目录和持久事件队列，可由第三方独立部署。 |
| 游戏服务端适配器 | 服务端 Fabric 组件，处理准入与统计；此集成不要求新增客户端模组。 |

当前开发工程要求 Node.js 24 或更新版本，使用 Electron 44.7.0；主服务需要 PostgreSQL。游戏所需 Java 版本取决于目标实例，当前隔离测试环境为 Minecraft `26.4 Snapshot 3`、Fabric `0.19.5` 和 Java `25.0.1`。这些版本描述当前实现与测试对象，不是对其他组合的兼容性承诺。

维护者通过发行连接配置提供服务地址、Microsoft 应用 ID 和信任信息，普通玩家无需注册自己的应用。Windows 用户数据默认保存在 `%APPDATA%\MC-Honer`，与安装目录分离。Microsoft 刷新令牌保存在本机受 Windows DPAPI 保护的凭据库中；平台登录会将短期 Minecraft 令牌交给配置的可信主服务进行官方身份复核，整合包远程端仅接收签名访问资格。

公开仓库当前不包含启动入口、依赖清单或服务配置，因此克隆后无法安装、运行或部署 MC Honer。本阶段不提供安装命令；公开程序包和对应的部署说明将在具备发布条件后另行提供。

## 验证范围与已知限制

内部 `0.1.0-alpha.1` 的 2026-10-13 开发记录包含 Windows Electron 窗口及便携包烟测、独立 PostgreSQL 18.4 回环实例测试、本机远程端签名更新，以及离线账号进入上述 Minecraft / Fabric 组合主菜单并正常退出。记录中的本机 HTTP 并发下载检查不代表公网容量测试。这些记录来自开发环境，本仓库不附带内部测试工具或原始日志。

本项目获批应用的真实 Microsoft 授权、正版玩家进入在线认证服务器、完整入服至离服统计、跨网络 OPL、公网部署和目标规模容量仍待验证。当前候选程序没有 Windows 代码签名；项目尚未提供面向公众的正式发行版或生产服务。
