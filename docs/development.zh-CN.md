# MC Honer Launcher 开发说明

[返回项目介绍](../README.md)

| 组件 | 当前实现与职责 |
| --- | --- |
| Windows 客户端 | Electron 桌面窗口；本地 Node.js 核心和 SQLite 管理实例及任务。界面通过限定的 IPC 操作访问核心。 |
| 主服务 | Node.js 与 PostgreSQL；负责身份核验、社交、目录、访问资格和统计汇总。 |
| 远程分发服务 | Node.js；使用签名清单、不可变内容目录和持久事件队列，可由第三方独立部署。 |
| 游戏服务端适配器 | 服务端 Fabric 组件，处理准入与统计；此集成不要求新增客户端模组。 |

开发工程要求 Node.js 24 或更新版本，使用 Electron 44.7.0；主服务需要 PostgreSQL。游戏所需 Java 版本取决于目标实例。2026-10-13 记录的隔离测试环境为 Minecraft `26.4 Snapshot 3`、Fabric `0.19.5` 和 Java `25.0.1`。这些版本描述所核对的依赖与历史测试对象，不是对其他组合的兼容性承诺。

维护者通过发行连接配置提供服务地址、Microsoft 应用 ID 和信任信息，普通玩家无需注册自己的应用。Windows 用户数据默认保存在 `%APPDATA%\MC-Honer`，与安装目录分离。Microsoft 刷新令牌保存在本机受 Windows DPAPI 保护的凭据库中；平台登录会将短期 Minecraft 令牌交给配置的可信主服务进行官方身份复核，整合包远程端仅接收签名访问资格。

公开仓库当前不包含启动入口、依赖清单或服务配置，因此克隆后无法安装、运行或部署 MC Honer Launcher。本阶段不提供安装命令；公开程序包和对应的部署说明将在具备发布条件后另行提供。

## 开发记录

内部 `0.1.0-alpha.1` 的 2026-10-13 开发记录包含 Windows Electron 窗口及便携包烟测、独立 PostgreSQL 18.4 回环实例测试、本机远程端签名更新，以及离线账号进入上述 Minecraft / Fabric 组合主菜单并正常退出。记录中的本机 HTTP 并发下载检查不代表公网容量测试。这些记录来自开发环境，本仓库不附带内部测试工具或原始日志。

上述记录还包含 OPL 同机双节点连接测试，不覆盖跨网络连接。该批候选程序没有 Windows 代码签名。这些历史结果不证明后续版本已通过真实 Microsoft 授权、正版进服、完整玩家会话统计或公网容量验收。

## 当前客户端

`0.1.0-alpha.15` 的窗口、托盘、快捷方式和安装器使用 MC Honer Launcher 名称，简称 MCHL。语言可在设置页切换，新建配置跟随系统语言，旧设置保留。安装标识、可执行文件名及 `%APPDATA%\MC-Honer` 数据目录保持兼容。账号名称、路径和远程发布者提供的内容不自动翻译。

普通客户端允许创建本机离线身份。离线启动要求可信远程签名声明公开整合包、允许 `offline` 账号，并明确开放 `offline-singleplayer` 或 `offline-opl`。前者不接受服务器地址；后者要求 OPL 运行，只可连接已启用的本机隧道。旧策略仅允许 `offline` 账号而没有这两种模式时不会自动放行。私有整合包继续要求正版身份与有效资格，测试资格不得附加商业付费条件。

上述限制覆盖启动器发起的启动和连接参数，不阻止玩家在游戏内手动操作，也不代替服务端在线认证。Microsoft 会话不能退化为无令牌的离线会话。

2026-10-15 在 Windows、Node.js `24.19.0`、Electron `44.7.0` 环境中，45 项定向测试通过，覆盖语言持久化、账户认证、签名离线策略、远程策略迁移和更新校验。源码客户端与打包客户端均通过设置页切换中英文、重新加载后保持选择及离线入口显示的实际窗口检查。本轮未启动 Minecraft，也未进行真实微软授权、跨网络 OPL 或现有安装覆盖升级验收。

Microsoft 应用尚未获准访问 Minecraft Services；真实授权与进服仍需在获得访问许可后验证。整合包发布前还需逐项核对第三方内容的分发许可，并确认不包含 Minecraft 原版代码或资源资产。

房间系统、武器配装和 SSH Editor 不属于当前开发范围。
